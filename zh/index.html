从任意应用一键呼出

需要时， 一键呼出

快捷呼出历史，选取内容粘贴回当前应用，用完再收起，多屏时跟随当前操作

同一个快捷键，呼出窗口，也能再次收起

可视化剪贴历史

复制了什么，一眼就知道

类型、时间、来源应用和内容预览都在卡片上，历史再多也能快速辨认和找回

每种内容，都看得清楚

不同内容自有合适的卡片

文本、图片、链接、颜色和文件会自动分类，并保留辨认、搜索、预览与再次使用所需的信息

文本

保留标题、列表和表格结构，可按原格式或纯文本粘贴

  • 标题、表格与链接
  • 正文关键词可搜索
  • 原格式或纯文本粘贴

图片

缩略图直接展示内容，可查看完整细节并导出复用

  • 完整图片预览
  • 分辨率与 GIF 识别
  • 导出为图片文件

链接

开启链接预览后，卡片自动补全网页标题与预览图

  • 标题与预览图
  • 粘贴前查看页面
  • 标题和网址都可搜索

文件

保留文件、文件夹和多文件记录，稍后仍可预览、定位和再次发送

  • 单个、多个或文件夹
  • 常见内容预览
  • 打开位置或复制路径

颜色

色块与数值同时可见，常用颜色格式可以快速转换

  • HEX / RGB / HSL
  • 真实色块预览
  • 一键转换颜色格式

按你的习惯工作

把 vPaste 调成顺手的样子

主题、快捷键与历史管理，按习惯设置

界面与行为

外观可跟随系统或选择深浅主题，支持中文与英文界面

剪贴板体验

显示链接标题与缩略图，记住上次的搜索、标签和滚动位置

数据与隐私

自选存储目录，按时间清理旧记录，也能迁移完整历史

键盘工作流

自定义呼出快捷键，用键盘搜索、预览，并选择粘贴格式

本机存储，数据自主

记录留在本机， 不上传服务器

  • 复制内容自动保存在本机
  • 可排除敏感内容与指定应用
  • 自选存储位置，按时间清理历史
  • 在 Windows 与 macOS 之间手动迁移历史
  • 链接预览开启时才请求对应网页
