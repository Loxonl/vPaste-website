## 首帧封面

独立封面为 [final/vpaste-cover-1440p.png](final/vpaste-cover-1440p.png)（2560×1440），取自 **0 秒 / 第 0 帧**。视频前 1 秒完整静止展示该画面，片尾 39.3–40 秒再次静止展示。原来的 39 秒现在处于片尾淡入过程，不再作为封面取帧点。

品牌开屏为默认显示首帧的播放器提供完整封面画面；具体平台是否另行选取缩略图，以平台实际显示为准。需要手动取片尾帧时可使用 39.4 秒 / 第 1182 帧。显示网址无 HTTPS 前缀，蓝色浅底并带下划线。

## 编辑和导出

```powershell
npm ci
npm run prepare:revised
npm run check:1440
npm run render:1440
npm run studio:revised
```

时间与标题在 `src/revised-timeline.ts`，其时间仍是原功能演示的局部时间。`src/revised-timing.json` 统一定义新增开屏、过渡和 1.2 秒偏移；画面与音效都使用此偏移。双语文案在 `src/revised-copy.ts`，画面在 `src/RevisedPromo.tsx`，入口为 `src/revised-index.tsx`。

本轮只重新生成 `soundtrack-revised.wav`，沿用已验收的卡片及图片素材，未重新提取后来可能已修改的官网页面。按键和转场音效后移，背景音乐仍连续覆盖 40 秒并正常淡出。

右上角沿用客户端 `PlaylistAddCheckRounded` 和 `SettingsOutlined`；全部分类使用 `AppsOutlined`。默认分类为 📝 文本、🖼️ 图片、🔗 链接、🎨 颜色、📁 文件。表格采用 10.5px 设计字号，英文列宽为 38% / 24% / 38%；实际 1440p 由 1920×1080 设计坐标重新栅格化。

Windows 11 图标来自 Devicon，Mac Finder 图标来自 IconPark；本地素材与许可证见 `public/promo/PLATFORM-ICONS.md`。

呼出、搜索、Space 预览和连续粘贴共用 `KeyboardHint` 样式与统一按键声。`src/revised-keypresses.json` 记录局部时间，与 `src/revised-timing.json` 的偏移共同决定成片时间。

`check:1440` 检查 TypeScript、双语关键帧，以及首帧与 0.5 秒、1 秒、39.4 秒、39.8 秒、最终帧的一致性。检查包含开场向上衔接、双卡、搜索输入、Space 触发、队列、拖拽和跨平台迁移。开屏与片尾使用相同的合成图层来统一文字抗锯齿；封面比较只允许 Chromium 少量边缘取整差异（不超过 0.01% 像素、每通道 2/255）。交付时另检查编码后的第一帧、完整视频解码、分辨率、时长、帧率和音轨。

命令输出在 `out/revised-1440/`。发布文件保存在 `final/`，旧版及修改前源码保存在 `archive/2026-10-08/`。
